# QA Portfolio - Конопацкая Анна

Портфолио тестовых заданий, выполненных при отклике на вакансии **Manual QA Engineer**. Включает примеры ручного функционального тестирования, баг-репортинга и работы с API.

## Содержание

| # | Проект | Что показывает |
|---|---|---|
| 1 | [Баг-репорт: stavkinasport.com](./01-bug-report-stavkinasport/bug-report-README.md) | Исследовательское тестирование реального сайта, поиск и оформление 26 дефектов на Desktop и Mobile |

## Навыки, отражённые в портфолио

- Исследовательское и тест-кейсовое (scripted) тестирование
- Оформление баг-репортов по стандартной структуре (шаги / ожидаемый / фактический результат / приоритет)
- Проектирование тест-кейсов на основе граничных значений и классов эквивалентности
- Кросс-браузерное и кросс-девайсное тестирование (Desktop / Mobile / Tablet)
- Тестирование UI/UX-поведения элементов (состояния, валидация, адаптивность)
- Работа с Postman: сборка коллекций, CRUD-тестирование REST API
