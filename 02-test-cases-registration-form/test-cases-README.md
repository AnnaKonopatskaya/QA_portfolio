# Тест-кейсы: форма регистрации

**Тип работы:** тестовое задание на позицию Manual QA Engineer
**Объект тестирования:** форма регистрации пользователя (`https://test/registr`)
**Формат:** классический тест-кейс (ID, раздел, предусловия, шаги, ожидаемый результат, приоритет, тип, статус)

## Задача

Спроектировать набор тест-кейсов для формы регистрации, покрывающий:
- граничные значения и валидацию всех полей ввода (логин, пароль, повтор пароля, email, дата рождения);
- позитивные и негативные сценарии;
- поведение UI (состояния кнопки, подсветка полей, плавающие лейблы);
- адаптивность на трёх разрешениях экрана (Desktop, Tablet, Mobile).

Отдельное внимание уделено:
- **граничным значениям** длины логина (4/5/20/21 символ) и пароля (5/6/33/34 символа);
- **граничному возрасту** регистрации - 89 / 90 / 91 год;
- **валидации email** по допустимым доменам;
- **визуальным состояниям** UI - цвет рамки активного поля, поведение плавающего лейбла, состояние кнопки «Регистрация» (серая/зелёная) в зависимости от заполненности формы;
- **кросс-девайсности** - 3 отдельных кейса на корректное отображение формы на Desktop (1920×1080), Tablet (1024×768) и Mobile (414×896).
